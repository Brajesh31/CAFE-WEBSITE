# Code of Conduct

## Commitment

Café Delight welcomes participation from people with different backgrounds and experience. We want project discussions and contributions to remain respectful, constructive, and focused on improving the work.

## Expected behavior

- Be considerate and respectful in issues, reviews, and other project spaces.
- Give and receive feedback in good faith.
- Critique code and design without attacking people.
- Respect privacy and do not publish private information.
- Follow the project's contribution, security, and asset-licensing guidance.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate intimidation, unwanted sexual attention, doxxing, and disruptive conduct that prevents others from participating are not acceptable in project spaces.

## Maintainer response

The maintainer may remove content, close discussions, or restrict participation to keep collaboration safe and useful. Responses should be proportionate to the behavior.

For conduct concerns, contact the maintainer privately through GitHub [@brajesh31](https://github.com/brajesh31). Do not post private personal information in a public issue.

## Scope

This policy applies in repository issues, pull requests, reviews, and other project-related spaces, including when someone represents the project publicly. It supports respectful collaboration and does not prohibit good-faith technical disagreement.
