# ☕ Project Overview

Café Delight is a single-page static website concept built with HTML, CSS, Bootstrap, and vanilla JavaScript. It includes navigation, hero, about, menu cards, sample branch details, testimonial carousel, and a contact form layout.

## Intended audience
Learners exploring front-end fundamentals and developers reviewing a simple static site.

## Current capabilities
- Bootstrap navigation and carousel markup.
- Hero image and introduction.
- Three menu cards and three sample branch entries.
- Contact form markup with no submission service.
- Custom stylesheet and a local smooth-scroll script that is not currently loaded.

## Not implemented
There is no API, database, account system, online ordering, reservation workflow, payment integration, admin panel, or working contact delivery. Treat branch names and testimonials as sample content until verified.

## Visitor flow
1. Open the page.
2. Navigate between About, Menu, Branches, Testimonials, and Contact.
3. View sample menu and café content.
4. Interact with the Bootstrap carousel when its CDN dependency loads.
5. See a contact form layout that does not transmit messages.

The project should remain static unless a real requirement justifies additional infrastructure.
