# 🔎 Search Engine Optimization Guide

The current page has a title, viewport declaration, and language attribute. A production-ready SEO baseline should include reviewed metadata and verified business information.

Recommendations:
- Write an accurate unique title and meta description.
- Add Open Graph metadata with a licensed preview image.
- Add canonical URL only after the public domain is known.
- Keep one descriptive page-level `h1` and logical section headings.
- Use meaningful link text and text-based content.
- Optimize image size and dimensions.
- Add structured data only for verified business facts.
- Do not publish fictitious addresses, hours, ratings, or testimonials for SEO.

Do not add LocalBusiness or Restaurant schema using placeholder details.
