# 🧰 Maintenance Guide

## Routine review
- Verify menu, branch, opening-hour, and contact copy with the owner.
- Review Bootstrap and Google Fonts resources.
- Check image licenses and attribution.
- Validate links and exact asset path case.
- Test mobile, tablet, and desktop widths.
- Review console/network errors.
- Revisit accessibility, privacy, and security when features change.

| Change | Update these documents |
|---|---|
| New page/section | README, architecture, project structure, SEO |
| New image/font | Content guide, asset inventory, license notices |
| New dependency | Architecture, security, installation, changelog |
| Contact integration | API, privacy, security, deployment, testing |
| Ordering/booking | Overview, architecture, threat model, support |
| Hosting change | Deployment, installation, troubleshooting |

Keep documentation aligned with the implementation. Never describe proposed work as already delivered.
