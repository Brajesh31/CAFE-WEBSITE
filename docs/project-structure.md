# 🗂️ Project Structure

```text
CAFE-WEBSITE/
├── .github/                 # Issue/discussion templates and workflows
├── css/styles.css           # Custom page styles
├── docs/                    # Guides, diagrams, templates, records
├── examples/                # Reserved for self-contained examples
├── images/                  # Café, coffee, pastry, sandwich assets
├── js/script.js             # Smooth-scroll handler, currently unlinked
├── index.html               # Main page
├── image.png                # Additional image, currently unreferenced
├── .env.example             # No environment values currently required
├── README.md                # Project entry point
├── CHANGELOG.md             # Change history
├── CONTRIBUTING.md          # Contribution workflow
├── CODE_OF_CONDUCT.md       # Community expectations
├── SECURITY.md              # Vulnerability policy
├── SUPPORT.md               # Support guidance
├── ROADMAP.md               # Proposed improvements
└── LICENSE                  # Code license
```

## Ownership by area
- HTML sections and resource links belong in `index.html`.
- Presentation belongs in `css/`.
- Browser interactions belong in `js/`.
- Local visuals belong in `images/`.
- Technical and operational guides belong in `docs/`.

Use lowercase kebab-case for new documentation. Preserve exact asset filename case. Avoid empty directories and placeholder files. Update this document when the structure changes.
