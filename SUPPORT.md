# Support

## Where to ask

- For reproducible bugs or focused proposals, open an issue in the [GitHub repository](https://github.com/Brajesh31/CAFE-WEBSITE/issues).
- For local setup, review [Installation](docs/installation.md) and [Troubleshooting](docs/troubleshooting.md).
- For suspected vulnerabilities or unexpected data collection, follow [SECURITY.md](SECURITY.md) and report privately.
- For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact the maintainer through [@brajesh31](https://github.com/brajesh31).

## Include useful details

Describe the browser and operating system, the page section, reproduction steps, and relevant console or network errors. Include a screenshot for layout problems. Do not include personal information or secrets.

## Project scope

This is an individual static website prototype, not a real café ordering, booking, or customer-support service. The contact form does not send messages, and the sample addresses and testimonials are not verified. There is no uptime or response-time commitment.
