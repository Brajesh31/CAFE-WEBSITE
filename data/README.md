# 🗃️ Data and Content Policy

The current project has no database or structured data store. Page copy and menu entries are defined directly in `index.html`.

This directory is reserved for future non-sensitive, reviewed structured content if required. Do not store customer messages, account details, payment data, credentials, or personal data in the repository.

Before introducing structured content, document its owner, source, update process, validation, access rules, and privacy impact.
